# TabPFN Comparison Figure Plan

## Purpose

Add a TabPFN partial-dependence row to the existing paper comparison figure generated by `src.interpretability.paper_comparison.feature_effects`.

Final row order:

1. XGBoost SHAP
2. TabPFN PDP
3. ChebyKAN PDP
4. FourierKAN PDP

TabPFN uses seed `42` to match the seed-42 Stage C convention used by the existing XGBoost and KAN comparison artifacts.

## Required Artifacts

TabPFN checkpoint:

```text
checkpoints/stage-c-tabpfn-full-seed42/model-*.joblib
```

TabPFN evaluation artifacts:

```text
outputs/eval/tabpfn_paper/stage-c-tabpfn-full-seed42/X_eval.parquet
outputs/eval/tabpfn_paper/stage-c-tabpfn-full-seed42/X_eval_raw.parquet
outputs/eval/tabpfn_paper/stage-c-tabpfn-full-seed42/feature_types.json
```

TabPFN ranking artifact:

```text
outputs/interpretability/tabpfn_paper/stage-c-tabpfn-full-seed42/data/tabpfn_feature_ranking.csv
```

Existing comparison inputs are still required for XGBoost, ChebyKAN, and FourierKAN under their default paper artifact directories.

## Generate Missing Artifacts

Train the seed-42 TabPFN run if the checkpoint and eval artifacts are missing:

```bash
uv run python main.py --stage train \
  --config configs/experiment_stages/stage_c_explanation_package/tabpfn/all_features/train/tabpfn_full_seed42.yaml
```

Generate TabPFN ablation ranking if `tabpfn_feature_ranking.csv` is missing:

```bash
uv run python scripts/tabpfn_permutation_importance.py
```

If the ranking script still writes to the legacy non-seed path, copy or regenerate the CSV under:

```text
outputs/interpretability/tabpfn_paper/stage-c-tabpfn-full-seed42/data/tabpfn_feature_ranking.csv
```

## Regenerate Comparison Figure

```bash
uv run python -m src.interpretability.paper_comparison \
  --tabpfn-dir outputs/interpretability/tabpfn_paper/stage-c-tabpfn-full-seed42 \
  --tabpfn-eval-dir outputs/eval/tabpfn_paper/stage-c-tabpfn-full-seed42 \
  --output-dir outputs/interpretability/comparison/tuned_big_kan_vs_xgboost
```

Use `--tabpfn-checkpoint checkpoints/stage-c-tabpfn-full-seed42/model-<timestamp>.joblib` if the checkpoint should be selected explicitly.

## Notes

- TabPFN PDP uses `predict_continuous()` when available and falls back to `predict()`.
- TabPFN PDP is computed on a fixed seed-42 evaluation subsample to keep runtime manageable.
- TabPFN is presented as model-agnostic PDP plus ablation ranking, not native symbolic interpretability.
